# src/rules — 规则

把规则从引擎中拆出来，使每条规则独立可测。

## 计划中的文件

| 文件 | 职责 |
|---|---|
| `MovementRules.ts` | 移动可达性（移动距离）、节点占用、封路影响 |
| `CombatRules.ts` | 攻击合法性、伤害结算管线（加算 → 减算 → 钳位 → 消耗状态） |
| `TurnRules.ts` | 回合结构、技能 CD 递减、抽牌、胜负判定 |
| `TargetRules.ts` | 各类技能 / 功能牌的目标合法性（含"必须产生效果"原则） |

## 关键约定

- 本目录必须与 `src/core` 一样保持纯粹、确定、零环境依赖。
- 任何规则改动都应先更新 `RULES.md`，再改这里的代码与测试。
