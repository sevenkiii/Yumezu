# src/cards — 功能牌

功能牌池、抽牌逻辑与 11 张牌的定义。

## 计划中的文件

| 文件 | 职责 |
|---|---|
| `Card.ts` | 功能牌类型与通用接口（合法性检查 + 效果生成） |
| `CardPool.ts` | 独立等概率抽取（有放回），由 `gameSeed` 的 `cards` 子流驱动 |
| `definitions/` | **每张牌一个文件**（见该目录 README） |

## 关键约定

- V1 牌池为 11 张，不含「灵感」。
- 抽牌不使用牌库 / 弃牌堆 / 洗牌。
- 手牌上限 5；开局 3 张；回合开始若手牌 < 5 则抽 1 张。
- 使用功能牌本身即消耗一次行动。
