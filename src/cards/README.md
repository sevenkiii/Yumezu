# src/cards — 功能牌

功能牌接口、牌池与 11 张牌的定义。

## 文件

| 文件           | 职责                                                              |
| -------------- | ----------------------------------------------------------------- |
| `Card.ts`      | `CardDefinition` 接口与定义查询                                   |
| `CardPool.ts`  | 牌池、抽牌（有放回）、手牌上限；由 `gameSeed` 的 `cards` 子流驱动 |
| `definitions/` | **每张牌一个文件**（见该目录 README）                             |

## 关键约定

- V1 牌池为 11 张，不含「灵感」。
- 没有牌库 / 弃牌堆 / 洗牌；重复持牌合法。
- 手牌上限 5；开局 3 张；回合开始若手牌 < 5 则抽 1 张。
- 使用或弃掉功能牌消耗本回合的**功能牌槽位**；角色操作槽位仍然可用（RULES.md §1）。

入口：`Card.ts`、`CardPool.ts` 与 `definitions/index.ts`。
