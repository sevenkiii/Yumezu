# src/map — 地图

平面图的生成、校验与出生点选择。**全部由 `mapSeed` 决定，可完全复现。**

## 计划中的文件

| 文件 | 职责 |
|---|---|
| `Graph.ts` | 图结构（顶点 / 边）、无权最短路、图距离与移动距离 |
| `MapGenerator.ts` | 随机点 → Delaunay → MST → 随机补边，生成平面图 |
| `triangulation.ts` | Delaunay 三角剖分的唯一封装处（外部库只允许在此引用） |
| `MapValidator.ts` | 连通性、度数、直径、桥 / 割点等阈值检查（全部参数化） |
| `SpawnGenerator.ts` | 选择公平的两个出生中心与出生区域 |

## 关键约定

- 相同 `mapSeed` → 完全相同的节点坐标、节点 ID、边集合与出生点。
- 生成失败重试有上限，耗尽后抛出带原因统计的错误；**不得静默放宽条件**。
- 距离分为「图距离」与「移动距离」两种，不可混用（见 `RULES.md` §6）。
