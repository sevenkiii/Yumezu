# src/map — 地图

随机平面图的生成、校验与出生点选择。**全部由 `mapSeed` 决定，可完全复现。**

## 文件

| 文件 | 职责 |
|---|---|
| `Graph.ts` | 图结构、无权最短路、可达性、连通分量 / 桥 / 割点 / 直径 |
| `triangulation.ts` | Delaunay 三角剖分的唯一封装处（第三方库只在这里引用） |
| `MapGenerator.ts` | 采点 → Delaunay → 随机生成树 → 补边 → 修复 → 校验 → 重试 |
| `MapValidator.ts` | 统计与阈值检查（连通性、度数、单线路径、直径、桥、割点、边交叉） |
| `SpawnGenerator.ts` | 出生中心候选、区域计算、地图中心 |
| `fixtures.ts` | Phase 1 遗留的固定网格地图（测试用基准，仍满足同一套校验） |

## 生成流程

```
mapSeed → points 子流采点（单位正方形 + 最小间距，放不下时逐步放宽）
        → 打乱点序并分配 id
        → Delaunay 三角剖分
        → edges 子流：随机顺序 Kruskal → 随机生成树（保证连通）
        → 随机补边到目标边数（40 ~ 50，由 seed 决定）
        → 修复阶段：消除度数 1 的节点与桥（只加尚未使用的 Delaunay 边）
        → Validator → 合格则接受，否则用同一 seed 的下一个随机块重试
        → spawn 子流：从全部合格候选里随机选一对出生中心
```

修复阶段是必要的：随机生成树必然带桥与叶子，纯随机补边命中"无桥 + 无度数 1"的概率很低（实测约 45 次尝试才成功一次）。修复只使用 Delaunay 边，不改变平面性与边数上界，也不放宽任何校验条件。加入修复后 40 个 seed 全部通过，平均 1.7 次尝试。

## 关键约定

- 相同 `mapSeed` → 完全相同的节点坐标、节点 ID、边集合与出生点。
- 三种子流 `points` / `edges` / `spawn` 与 `gameSeed` 完全独立。
- 失败 `maxAttempts` 次后抛 `MapGenerationError`（带失败原因统计），**不静默放宽条件**。
- 距离分「图距离」与「移动距离」两种，不可混用（见 `RULES.md` §6）。
