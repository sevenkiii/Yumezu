# src/map — 地图

图结构、距离计算与出生区域。随机地图生成（Phase 2）将来此扩展。

## 文件

| 文件 | 职责 | 状态 |
|---|---|---|
| `Graph.ts` | 图结构、无权最短路、可达性、连通分量 / 桥 / 割点 / 直径 | 已实现 |
| `fixtures.ts` | Phase 1 固定地图：6x5 网格（30 节点 / 49 边 / 直径 9） | 已实现 |
| `SpawnGenerator.ts` | 由出生中心计算出生区域 | 已实现（仅区域计算） |
| `MapGenerator.ts` | 随机点 → Delaunay → MST → 随机补边 | Phase 2 |
| `MapValidator.ts` | 连通性、度数、直径、桥 / 割点等阈值检查（参数化） | Phase 2 |
| `triangulation.ts` | Delaunay 的唯一封装处（外部库只允许在此引用） | Phase 2 |

## 关键约定

- 相同 `mapSeed` → 完全相同的节点坐标、节点 ID、边集合与出生点。
- 生成失败重试有上限，耗尽后抛出带原因统计的错误，**不得静默放宽条件**。
- 距离分「图距离」与「移动距离」两种，不可混用（见 `RULES.md` §6）。

> 状态：Phase 1 使用固定网格地图；随机生成在 Phase 2。
