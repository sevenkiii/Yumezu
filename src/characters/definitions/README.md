# src/characters/definitions — 角色定义

**每名角色一个文件。** 新增角色时在此目录添加文件，并在 `index.ts` 登记。

| 文件        | 角色   | 定位                              |
| ----------- | ------ | --------------------------------- |
| `Nana.ts`   | Nana   | 单体爆发（地球仪，4 点伤害）      |
| `Lily.ts`   | Lily   | 位置操纵（换位，范围 3）          |
| `Melty.ts`  | Melty  | 区域支援 / 区域伤害（Melty Land） |
| `Mikage.ts` | Mikage | 预判 / 防守反制（影返）           |
| `Spica.ts`  | Spica  | 高机动突袭（星奔）                |
| `Urara.ts`  | Urara  | 区域控制（冻结）                  |
| `index.ts`  | —      | 汇总并导出全部角色定义            |

所有定义必须与 `RULES.md` §11 和 `STATS.md` 保持一致。
