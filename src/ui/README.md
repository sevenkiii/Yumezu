# src/ui — 网页界面

React + SVG 界面。**只负责显示状态与产生 Action，不修改游戏状态。**

## 计划中的文件

| 文件 | 职责 |
|---|---|
| `MapView.tsx` | 地图与角色的 SVG 渲染 |
| `DeployView.tsx` | 部署界面（点击式） |
| `HandView.tsx` | 手牌与功能牌使用 |
| `HudView.tsx` | 当前行动方、技能 CD、状态显示 |
| `i18n.ts` | 文案接口（默认中文，预留多语言） |

## 关键约定

- 不直接修改 `GameState`；所有变更都通过产生 `Action` 提交给引擎。
- 地图逻辑与地图渲染分离：UI 不参与寻路与规则判定。
- 文案一律走 i18n 接口，禁止在组件里硬编码字符串。
