# src/ui/i18n — 文案

所有面向玩家的文字都在这里，引擎只保留 id。

| 文件 | 职责 |
|---|---|
| `types.ts` | `UiText` 结构：角色 / 技能 / 功能牌 / 状态 / 提示语 / 格式化函数 |
| `zh-CN.ts` | 简体中文（当前唯一语言） |
| `index.ts` | `getText(locale)` 入口；新增语言时在这里登记 |

## 约定

- 文案的规则依据是 `RULES.md` §11 / §12；改规则时同步这里。
- 组件里不要出现中文/英文字面量，一律走 `text.xxx`。
- 带数字的句子写成格式化函数（例如 `text.format.hp(hp, maxHp)`），方便将来处理语序。
